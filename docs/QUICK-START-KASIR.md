## 🚀 BUKA SHIFT (Wajib sebelum transaksi!)

1. Klik **"Buka Shift"** dari notifikasi

## 🛒 TRANSAKSI PENJUALAN

### Tambah Produk:
- **Klik** card produk di katalog
- **Atau ketik** nama/barcode di kotak cari → **Enter**
- **Atau scan** barcode

### Ubah Qty:
- Klik angka qty → ubah → **Simpan**

### Hapus Item:
- Klik **🗑️** (ikon sampah)

---

## 💰 PEMBAYARAN

### Tunai
1. Klik **"Bayar"** (F9)
2. Pilih **Tunai**
3. Ketik uang diterima (misal: `50000`)
4. Sistem hitung kembalian otomatis
5. **Proses** → Print struk

### Transfer
1. **"Bayar"** → **Transfer**
2. Masukkan nominal **tepat** (tidak boleh lebih)
3. **Proses** → Print struk

### QRIS
1. **"Bayar"** → **QRIS**
2. Masukkan nominal **tepat**
3. Minta pelanggan **scan QRIS toko**
4. **Proses** → Status "Menunggu Pembayaran"
5. Owner konfirmasi nanti ✅

### Kredit (Piutang)
1. **"Bayar"** → **Kredit**
2. **Pilih pelanggan** (wajib!)
3. Bisa full kredit (Rp 0) atau DP dulu
4. **Proses** → Print struk "BELUM LUNAS"

### Campuran (Tunai + Transfer)
1. **"Bayar"** → Pilih **Tunai** → masukkan (misal: `100000`)
2. Klik **"+ Tambah Metode"** → **Transfer** → masukkan sisanya
3. **Proses** ✅

---

## 📋 TERIMA PELUNASAN PIUTANG

1. Tekan **F6** (dari layar kasir)
2. Masukkan **nomor transaksi** (SALE-00045) atau **pilih pelanggan**
3. Sistem tampilkan sisa piutang
4. Masukkan jumlah bayar (full atau sebagian)
5. Pilih metode (Tunai/Transfer)
6. **Proses** → Print bukti ✅

---

## 📊 TUTUP SHIFT (Akhir hari)

1. Menu **Shift** → **"Tutup Shift"**
2. Hitung **uang fisik** di laci (semua pecahan)
3. Masukkan jumlah total
4. Sistem tampilkan selisih:
   - **Rp 0** = Perfect! ✅
   - **+ (positif)** = Uang lebih (cek lagi!)
   - **- (negatif)** = Uang kurang (cek lagi!)
5. Tulis catatan jika ada selisih
6. **Tutup Shift** ✅

## ⚠️ TROUBLESHOOTING CEPAT

| Masalah | Solusi |
|---------|--------|
| "Tidak ada shift aktif" | Klik **"Buka Shift"** |
| "Stok tidak cukup" | Kurangi qty atau hubungi owner |
| "Pembayaran kurang" | Cek nominal atau pakai **Kredit** untuk sisanya |
| Struk pelanggan hilang | Menu **Riwayat** → cari transaksi → **Cetak Ulang** |
| Transaksi salah | Hubungi **Owner** (kasir tidak bisa void) |
| Printer tidak print | Cek nyala/kertas, atau **Ctrl+P** manual |
| QRIS belum lunas | Normal, owner konfirmasi nanti |
